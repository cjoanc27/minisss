Production Process Exercise

In this part of the study, you will work on a series of short production tasks.

Your goal is to learn a reliable way to set up a production process. You do not need any prior factory, engineering, or gaming experience.

A reliable way to set up a new production process

During these tasks, use a PILOT-FIRST approach:

  1. Build one complete pilot line.
  2. Run it to discover hidden process requirements.
  3. Report and correct the issue while the process is still small.
  4. Verify the corrected pilot.
  5. Scale the proven process.
